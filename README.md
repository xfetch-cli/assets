# xfetch assets

Shared brand assets for the xfetch ecosystem.

## Contents

- `logo/banner/xfetch.svg`: the banner used by READMEs and the website.

## Usage

The banner is hotlinked from:

```text
https://raw.githubusercontent.com/xfetch-cli/assets/main/logo/banner/xfetch.svg
```

Keep the path and the default branch stable; changing them breaks the READMEs,
the web hero and the organization profile.
